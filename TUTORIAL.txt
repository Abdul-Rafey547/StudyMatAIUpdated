1. PREREQUISITES & ENVIRONMENT SETUP
================================================================================
- Windows 10/11 with Python 3.10+ installed.
- Local Moodle LMS running on Apache / PHP (e.g., http://moodle.local or http://localhost).
- Google Chrome browser (or Chromium-based: Edge, Brave).
- Project directory: C:\StudyMateAI

Open PowerShell or Command Prompt in the project folder:
   cd C:\StudyMateAI

Install required dependencies:
   pip install -r requirements.txt

Verify that PyPDF and python-docx are installed for document processing:
   python -c "import pypdf, docx; print('PDF & DOCX tools ready!')"

2. CONFIGURING MOODLE WEB SERVICES & BACKEND CREDENTIALS
================================================================================
StudyMate AI uses the official Moodle REST Web Services API as its primary source
of truth. To configure your local Moodle:

1. ENABLE WEB SERVICES & PROTOCOLS:
   - Log into Moodle as Administrator (http://moodle.local).
   - Go to: Site administration -> Advanced features -> Check "Enable web services".
   - Go to: Site administration -> Server -> Web services -> Manage protocols.
   - Enable "REST protocol" (eye icon open).

2. CREATE EXTERNAL SERVICE:
   - Go to: Site administration -> Server -> Web services -> External services.
   - Click "Add".
   - Name: "StudyMate AI Service", Short name: "studymate_service".
   - Check "Enabled", "Authorized users only", "Can download files", "Can upload files".
   - Click "Add service".

3. ADD API FUNCTIONS:
   - Click "Functions" next to StudyMate AI Service.
   - Add the 15 required core functions:
     • core_webservice_get_site_info
     • core_enrol_get_users_courses
     • core_course_get_courses
     • core_course_get_contents
     • mod_assign_get_assignments
     • mod_assign_get_submission_status
     • mod_assign_save_submission
     • mod_quiz_get_quizzes_by_courses
     • mod_quiz_get_quiz_access_information
     • mod_quiz_get_user_attempts
     • mod_resource_get_resources_by_courses
     • mod_page_get_pages_by_courses
     • mod_book_get_books_by_courses
     • core_files_get_files
     • core_user_get_users_by_field

4. AUTHORIZE STUDENT & GENERATE LEAST-PRIVILEGED TOKEN:
   - Go to: Site administration -> Users -> Permissions -> Define roles.
   - Edit "Authenticated user" role and allow capability: `webservice/rest:use`.
   - Go to: External services -> Authorized users -> Add your student (e.g. `student1`).
   - Go to: Web services -> Manage tokens -> Create token.
   - Select student user: `student1`, Service: `StudyMate AI Service`.
   - Copy the generated 32-character hexadecimal token (e.g. `fc628508599b8251fb3e2a40af365124`).

5. CONFIGURE BACKEND ENVIRONMENT (.env):
   - Copy `.env.example` to `.env`:
     copy .env.example .env
   - In `.env`, ensure the following are set:
     MOODLE_URL=http://moodle.local
     MOODLE_TOKEN=your_student_token_here
     PORT=5000

3. STARTING THE BACKEND SERVER
================================================================================
In PowerShell:
   cd C:\StudyMateAI
   python backend/app.py

You will see:
   [INFO] Starting StudyMate AI Backend on 0.0.0.0:5000...
   * Running on http://127.0.0.1:5000

Keep this terminal open while using or testing the extension.

4. LOADING THE CHROME EXTENSION IN DEVELOPER MODE
================================================================================
1. Open Google Chrome.
2. In the URL bar, go to: chrome://extensions/
3. Toggle ON "Developer mode" in the top-right corner.
4. Click "Load unpacked" in the top-left corner.
5. Select the folder: C:\StudyMateAI\extension
6. Click "Select Folder".
7. Pin the StudyMate AI icon (purple gradient) to your Chrome toolbar.
8. If you make any frontend changes in the future, simply click the circular 
   reload button on the extension card in chrome://extensions/.

TEST 4: VERIFY ACTIVITY AVAILABILITY CATEGORIZATION & RULES
--------------------------------------------------------------------------------
Goal: Confirm the 9 availability states and verify that `notgraded` does not 
falsely complete unsubmitted assignments.

StudyMate AI categorizes coursework into strict states:
- AVAILABLE: Published, open for submission, unsubmitted (Actionable Pending).
- SUBMITTED: Student has submitted their work (Non-Pending).
- COMPLETED: Assignment graded or quiz attempts finished (Non-Pending).
- UPCOMING: Opening date is in the future (Non-Pending).
- CLOSED: Cut-off date or quiz timeclose has passed (Non-Pending).
- UNAVAILABLE: Hidden or restricted by teacher (Non-Pending).

Verification Steps:
1. Open the StudyMate AI Dashboard:
   - Click "Open Full Dashboard" in the popup (or right-click extension icon -> Options).
2. Look at the Coursework Overview table:
   - Tasks with no submission show status: "AVAILABLE".
   - Notice that assignments showing "Not graded" in Moodle remain AVAILABLE 
     and are NOT marked COMPLETED (verifying the `notgraded` substring bug fix).
3. In Moodle, submit one assignment.
4. Return to StudyMate AI and click "Refresh / Scan".
5. Notice that the submitted assignment updates its badge to "SUBMITTED" and 
   automatically clears from the pending count!

TEST 9: DIRECT MOODLE ASSIGNMENT SUBMISSION & UPLOAD VIA REST API

1. In the Review Solutions editor (or Dashboard), verify your solution is "APPROVED".
2. Click the green "Submit to Moodle" button.

7. TROUBLESHOOTING & COMMON QUESTIONS
================================================================================
Q: The extension shows 0 tasks after clicking Scan.
A: Verify:
   1. That your Moodle student user is actively enrolled in at least one course.
   2. That `MOODLE_TOKEN` in `.env` was generated for that student user.
   3. Run `python -c "import sys; sys.path.insert(0, 'backend'); from moodle.moodle_client import MoodleClient; print(MoodleClient().get_courses())"` to see the raw courses returned by Moodle.

Q: Clicking Scan returns "Cannot connect to Moodle server: [WinError 10061]".
A: Your local Apache server is not running. In XAMPP Control Panel, start Apache 
   (or run `C:\xampp\apache\bin\httpd.exe -d C:/xampp/apache`).

Q: How can I reset the local test database?
A: You can re-initialize the database anytime by running:
   python -c "import sys; sys.path.insert(0, 'backend'); from database.database import init_db; init_db()"
   Or delete `database/studymate.db` and it will be re-created automatically.

Q: Are my Moodle passwords or tokens stored in Chrome?
A: No. StudyMate AI strictly enforces a zero-token frontend design. All Moodle 
   tokens and credentials live in `backend/.env`. The Chrome extension communicates 
   solely with your local backend (`http://localhost:5000/api`).
